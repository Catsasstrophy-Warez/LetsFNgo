# Consolidated Conversation Requirements

The project began by combining the following app categories into one product: personal assistant; document/PDF research; email; meetings; second brain; research agents; coding agents; career; tutoring; CRM/sales; personal finance; investment research; scheduling; project management; SOP/procedure generation; field troubleshooting; maintenance/diagnostics; engineering calculations/design; digital twins; electrical simulation; automotive diagnostics/telemetry; automotive tuning/performance; meals/groceries; travel; study/flashcards; writing; social content; image creation/editing; video; music/audio; e-commerce; web creation; architecture/interiors; 3D; data visualization; agent platforms.

A competitive research program was defined at 25 reference products per category, approximately 900 product studies. The research is intended to extract workflow and UX principles, not clone protected interfaces.

The synthesis established these core ideas:
- one shared knowledge/world graph rather than mini-app silos;
- persistent Projects as context boundaries;
- specialized agents coordinated by an orchestrator;
- a universal object model spanning people, projects, documents, accounts, equipment, vehicles, measurements, procedures, simulations, media, agents, and workflows;
- Ask / Work / Run mental model;
- object-centric context: when the user is looking at an injector, compressor, transaction, document, or hotel, related tools inherit that context;
- source/evidence adjacency and claim-level provenance;
- meeting statements become structured decisions/commitments/tasks;
- finance preserves recorded data separately from AI interpretation;
- engineering unifies real equipment, digital twins, physics, electrical/control/process state, telemetry, faults, measurements, evidence, diagnosis, repair, verification, procedures, and training;
- automotive unifies garage, service history, CAN/OBD, DTCs, telemetry, performance, calibration, and vehicle digital twin;
- creative work preserves artifact lineage from idea through writing/image/audio/video/web/publishing/analytics;
- universal visualization and search engines serve every domain;
- agent activity and permissions are visible first-class UI.

The UX research consolidated the product into 18 screen families and a universal interaction grammar: Find -> Select -> Inspect -> Understand -> Act -> Verify -> Preserve.

The final architecture defined six conceptual layers: Experience, Intelligence, Work, World, Truth, Runtime.

Temporary codename: Nexus.
