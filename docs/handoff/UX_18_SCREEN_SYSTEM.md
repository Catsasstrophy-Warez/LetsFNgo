# 18 Canonical Screen Families

1. **Command Center** - Now, Continue, Watching, Today, universal Ask/Create/Analyze/Run.
2. **Project** - mission, objectives, objects, knowledge, sources, decisions, work, events, people, agents, outputs.
3. **Universal Search** - exact + full text + semantic + graph + structured + temporal retrieval.
4. **Object Detail** - identity, state, relationships, domain views, intelligence, actions.
5. **Collection/List** - table, compact list, cards, board, timeline, map, hierarchy, gallery; selection changes commands.
6. **Document** - text, tables, diagrams, charts, formulas, citations, code, measurements, 3D views, live queries, simulation snapshots.
7. **Research** - sources, analysis, claim ledger, contradictions, confidence, configuration applicability, citations.
8. **Conversation** - natural-language orchestration producing text, artifacts, charts, simulations, or actions.
9. **Meeting** - notes, transcript, participants, decisions, commitments, questions, claims, tasks, related objects.
10. **Timeline** - human actions, equipment events, measurements, agents, communications, maintenance, decisions.
11. **Task/Workflow** - objective, reason, inputs, evidence, owner, dependencies, gates, success condition, output.
12. **Calendar** - fixed, flexible, and conditional time.
13. **Investigation/Diagnostics** - observations, hypotheses, system truth, evidence, discriminating next test, first divergence.
14. **Telemetry/Visualization** - guided, technician, expert modes; gauges, plots, scopes, histograms, scatter, heatmaps, spectrum, state/event views.
15. **Simulation/Digital Twin** - hierarchy, inspector, runtime state, signals, connections, timeline and truth-layer overlays.
16. **Creative Workspace** - select -> direct edit -> AI action -> variants -> compare -> accept/merge.
17. **Agent Activity** - goal, plan, progress, inputs, actions, tools, evidence, outputs, errors, approvals.
18. **Settings/Permissions** - trust control center, agent/project/action/data-source policies.

## Universal interaction grammar
Find -> Select -> Inspect -> Understand -> Act -> Verify -> Preserve.

AI participates throughout but does not replace the underlying state model.

## Desktop
Navigation | Context | Workspace | Intelligence. Auxiliary panels collapse. Workspace dominates.

## iPad
Workspace first; Context and Intelligence become collapsible side/bottom regions. Pencil supports annotation, schematic interaction, 3D selection, handwriting, and markup.

## iPhone
Full-screen object/artifact. Bottom contextual bar: Context | Ask | + | Actions | More. Swipe up for Intelligence; sideways for related objects. Do not shrink desktop.

## Selection behavior
Selection changes the command surface. One item: Open/Ask/Analyze/Link. Multiple items: Compare/Group/Export/Run Analysis. Domain selections expose domain commands such as Trace/Measure/Simulate.

## Empty states
Teach the next useful action rather than displaying "nothing here".

## Errors
Classify as user input, data/source, system/runtime, agent/tool, or evidence/verification. Always show what happened, what survived, and next actions.

## Progress
Prefer inspectable progress over indefinite spinners: sources checked, tests complete, topology stages built, agent steps finished.

## Accessibility
Dynamic Type, VoiceOver, keyboard-only operation, high contrast, reduced motion, large targets, non-color status encoding, table equivalents for charts, captions/transcripts.
