# Competitive Research Synthesis

The conversation defined a research program covering 36 selected categories with 25 significant reference products per category (approximately 900 product studies). The purpose is not to reproduce rankings or clone protected UI expression. It is to extract workflows, information architecture, interaction grammar, strengths, weaknesses, and transferable concepts.

## Selected categories
Personal assistant; document/PDF research; email; meetings; second brain; research agents; coding agents; career; tutoring; CRM/sales; personal finance; investment research; scheduling; project management; SOP/procedures; field troubleshooting; maintenance; engineering; digital twins; electrical simulation; automotive diagnostics; automotive tuning; meals/groceries; travel; study; writing; social content; images; video; music/audio; commerce; web creation; architecture/interiors; 3D; data visualization; agent platforms.

## Major findings
1. Strong products converge across category boundaries. Research becomes knowledge management; meetings become workflow; assistants become agents; creative suites converge into pipelines.
2. The durable primitives are Conversation, Artifact, Context, Sources, Actions, and History.
3. Object-centric navigation scales better than chat-centric history.
4. Projects should be context boundaries, not folders.
5. Selection should change the command surface.
6. Sources/evidence should remain adjacent to conclusions.
7. Agent work should be visible and inspectable rather than hidden behind indefinite loading.
8. Expert applications need density modes instead of one complexity level.
9. Mobile should be purpose-built around field/object/task workflows.
10. The best combined architecture is one world model expressed through 18 screen families.

## Transferable UI principles
- Home reports state changes rather than advertising modules.
- Context replaces navigation where possible.
- Object Detail is a universal screen grammar.
- Research exposes source/claim/contradiction structure.
- Meeting statements can promote into commitments, decisions, tasks, claims, and relationships.
- Calendar supports fixed, flexible, and conditional time.
- Diagnostics expose system truth, display truth, evidence, hypotheses, and next discriminating test.
- Telemetry supports Guided, Technician, Expert depths.
- Creative AI operates inside the medium on selected objects.
- Permissions are a first-class trust surface.
