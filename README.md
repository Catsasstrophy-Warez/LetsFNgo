# LetsFNgo — Nexus

An Apple-first native AI operating environment for iPhone, iPad and Mac. It is built on one canonical world model:
`Project → Object → Relationship → Event → Evidence → Action`.

- `docs/handoff/`: the product specification and locked decisions. Start with `START_HERE_PROMPT.txt`.
- `docs/BUILD_PLAN.md`: package plan, schemas, dependency graph, Golden Vertical Slice acceptance plan, risks. It also covers the local layered LLM and the Apple Intelligence integration.
